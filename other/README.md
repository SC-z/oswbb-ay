# Other Local Assets

This directory holds non-engineering payloads that should not sit beside source code:

- `archive/`: large OSWbb sample archives used by local regression tests.
- `oswbb-upstream/`: upstream OSWatcher scripts and bundled analyzer assets.
- `local-ai/`: local model files, llama.cpp runtimes, and downloaded archives.
- `build-artifacts/`: locally built binaries.
- `python-env/`: local Python environment remnants that are not part of the Go tool.
- `macos-metadata/`: Finder metadata files moved out of source directories.

Only this README is intended to be tracked. The payload directories are local assets.
